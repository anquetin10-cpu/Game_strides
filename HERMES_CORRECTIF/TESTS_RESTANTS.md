# TESTS RESTANTS — non exécutés ou non vérifiables ici

Tous les tests de ce correctif ont tourné dans un navigateur Chromium sans écran, avec rendu logiciel (SwiftShader) et, le plus souvent, en émulation iPhone 13 paysage (844 × 390, tactile). **Aucun n'a tourné sur un iPhone réel.** Les cadences d'image, la chauffe, la mémoire et le comportement de Safari ne sont donc pas mesurés.

| COR-I01 | Safari sur iPhone : commandes multipoints, rotation, arrière-plan, session prolongée | **Non testé** | Aucun appareil disponible. À faire sur un iPhone identifié (modèle, iOS, build affiché dans le menu pause), avec les états E04, E05, E06 et E08. Charger un état sur l'appareil demande l'inspecteur web de Safari sur Mac (voir `ETATS_TEST/LISEZMOI.md`). |
